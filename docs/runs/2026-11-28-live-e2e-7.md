## Still open

- **Engine speed at large scale:** the user's story (10 000 customers, 500 pairs a day, 14 months)
  generates ~800 k rows; one engine run takes ~26 s plus ~16 s DuckDB store, and the A5 gate runs it up
  to 6× per attempt (seed 42 + 5 robustness seeds), so one A5 attempt takes ~5 min.
- **Segment point with an unscoped curve:** the shoe story's `defect_prob` curve stayed unscoped while
  its point names `segment: sportovní`, so defects rise for every category. Nothing checks that a
  segment point's curve is scoped to the segment when the curve's records carry that field.
